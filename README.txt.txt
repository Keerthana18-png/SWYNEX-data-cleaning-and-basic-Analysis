SWYNEX TASK 2

Data Cleaning and Basic Analysis

Project Title

Globin Protein Sequence Analysis Using Python

Objective

To read, process, clean and analyse globin protein sequences stored in FASTA format.

Dataset

Five globin protein sequences from different organisms:

- Horse
- Human
- Mouse
- Chicken
- Zebrafish

Tools Used

- Python 3.15
- Python IDLE
- FASTA file format
- Collections module

Analysis Performed

1. FASTA file reading
2. Protein sequence extraction
3. Sequence length calculation
4. Amino acid composition analysis
5. Comparative protein analysis
6. Sequence quality checking
7. Basic statistical analysis

Expected Outcome

To obtain a cleaned and organised protein sequence dataset and generate basic statistical summaries of globin proteins.
