SWYNEX Task 2 – Data Cleaning and Basic Analysis

Project Overview

This project performs data cleaning, validation and basic comparative analysis of five globin protein sequences using Python.

Objectives

- Analyse five protein sequences in FASTA format.
- Calculate protein sequence lengths.
- Identify amino acid composition.
- Detect empty sequences and invalid amino acids.
- Generate comparative protein analysis reports.
- Visualise sequence length differences using a bar graph.

Tools and Technologies

- Python 3.15
- Matplotlib
- FASTA file format
- GitHub

Dataset

The dataset contains five globin protein sequences from different organisms.

Analysis Performed

1. FASTA file parsing
2. Sequence validation
3. Amino acid frequency analysis
4. Protein sequence length comparison
5. Graph generation
6. Automated report generation

Results

The analysis successfully processed five protein sequences and generated a comparative sequence-length graph and a text-based analysis report.
